# ai-automation-portfolio

Portfolio site for AI automation work. Next.js static export, with all copy in `content/`.

The spec is in [`docs/PRD.md`](docs/PRD.md). Status: Phase 1 (content layer) done; Phases 2-5 (home page, hero demo, case-study pages, QA and deploy) are next.

## Commands

- `npm run dev`: local dev server
- `npm run build`: static export to `out/`
- `npm test`, `npm run lint`, `npm run typecheck`, `npm run format`
- `npm run check:todo`: lists unresolved `[TODO: ...]` tokens in `content/` and exits non-zero if any remain
